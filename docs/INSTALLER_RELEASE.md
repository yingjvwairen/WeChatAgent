# Windows 安装发行版 0.4.5

Windows x64 安装包包括桌面控制台、控制台运行环境、Reader 源码和 UIA/OCR 所用的本机辅助程序。安装包构建时从随包源码编译辅助程序，首次启动和升级时按发行清单校验后部署。

安装后选择本机已安装的 DSH 程序和微信程序。保存 DSH 路径后，Reader、媒体和 OCR 可使用该 DSH 自带的 Python 3.12 创建独立环境。在连接设置中核验账号和数据库，在准备组件页安装 OCR 依赖、校验识别模型。完成本机窗口标定和音频设置后再启用发送。操作入口见[日常使用](DAILY_USE.md)。

原位置升级保留账号数据、人格、会话授权和本机标定。升级前先停止后台服务并退出桌面控制台，防止正在运行的助手占用旧文件。使用源码迁移到另一台电脑时，按[副机部署说明](SECONDARY_PC_DEPLOYMENT.md)重新准备依赖和本机标定。

从源码创建安装程序时，使用 `npm run installer:runtime` 准备内置控制台运行环境，再执行 `npm run installer:build`。构建输出位于 `release/installer/`。
