# 日常使用

以下针对已完成配置的本机。运行依靠 DSH、微信和本项目，不需要打开 Codex。

## 每次使用

1. 手动登录现有微信，窗口不要最小化；可以放在副屏，不必一直保持前台。
2. 打开 DSH 并保持运行。
3. 双击项目根目录的 [WeChatAgent.cmd](../WeChatAgent.cmd) 启动机器人。
4. 双击 [Open-WeChatAgent-Console.cmd](../Open-WeChatAgent-Console.cmd) 打开控制台；也可访问 [本机控制台](http://127.0.0.1:3210)。重复打开会复用已运行的控制台。

停止机器人用 [Stop-WeChatAgent.cmd](../Stop-WeChatAgent.cmd)。**关闭浏览器页面不会停止机器人**。日常使用不需要重新执行首次配置。

## 功能在哪里

在“概览”选择电脑使用方式，在“聊天”管理回复对象和每个聊天的设置。打开“能力 → 语音服务”可设置语音识别与合成。“表情包”集中管理本地图片、GIF 与当前账号的共享表情池。

回复形式由机器人根据对话自动选择，没有单独的“回复方式”设置项。

网址、代码块和超过 400 字的语音候选会转为文字，方便复制。语音生成或设备准备失败时，队列确认所有分段都尚未提交，才会改发一次原文。只要已有分段可能已发出，就按原投递查询回执。

| 位置 | 操作 |
| --- | --- |
| 聊天 → 添加聊天 | 从本机微信搜索好友或群聊，选择后添加。最多 32 个。已启用的聊天会直接出现在列表中，可分别设置模式、人格、能力和工作区。 |
| 能力 → 语音服务 | 分别选择语音识别和语音合成的处理方式。默认使用本地，可任意组合。切到云端后填写兼容 OpenAI 音频协议的完整接口地址、模型和密钥。合成还需填写音色 ID。保存后可点击“测试短句识别”或“试听合成音色”。 |
| 普通文件发送 | 在助手模式中为目标聊天开启既有的文件收发功能。助手可将当前工作区中的 PDF 等文件经 UIA 发到该聊天，单文件最大 50 MiB，可在发送队列查看结果。 |
| 表情包 → 本地图片与 GIF | 选择包含 PNG、JPEG 或 GIF 的本机素材文件夹，选择图片或表情配图后导入。修改名称与标签可以帮助机器人按对话挑选，修改后保存。 |
| 聊天 → 选择好友或群聊 → 发送队列 | 查看发给这个聊天的待发正文、语音内容和附件名称。发送中、需核对和最近发送记录分开展示。可用操作包括暂停、继续、取消及确认草稿已清除。 |
| 概览 → 电脑使用方式 | 用“UIA 快速模式”选择发送方式：开启使用 UIA 控件定位与快速粘贴；关闭使用 OCR 快速定位。两条链路均在需要操作时借用焦点并归还。 |
| 文字逐字输入 | 仅作用于 OCR 的文字正文，默认关闭并快速粘贴，开启后模拟逐字输入。切到 UIA 后自动隐藏该选项。 |
| 微信离屏 | UIA 下可独立开启，将微信停放在全部显示器之外；关闭后恢复程序管理的位置。离屏不代表不占用键盘焦点。 |

群聊的自然参与模式会结合消息和上下文判断是否回应。“唤醒后回复”继续按真实 @、唤醒词和拍一拍等原有条件处理。

不再单独提供旧“共享电脑模式”开关及关闭后的长期前台发送链路。关闭“UIA 快速模式”时，沿用 OCR 的快速联系人搜索与焦点交接；正文默认快速粘贴。需要模拟打字时开启“文字逐字输入”，只改变 OCR 文字正文，搜索词仍复制粘贴，图片、GIF 和语音不受影响。开启逐字输入后，正文越长，输入这一段占用前台的时间也会越长，不能套用快速粘贴的耗时。

两条链路都保留操作保护。UIA 的文字、图片和语音开始需要短暂借用微信焦点；语音录制及提交可在后台完成。OCR 的语音开始和提交分别借用焦点，录制期间可以操作其他窗口。切换会保存设置，已有未确认结束的输入或录音会阻止切换；切换本身不解除发送队列暂停。

主电脑或副电脑只是部署位置，不是不同的发送模式。两台电脑都能选择 UIA 或 OCR 链路。项目没有独立“双机模式”或主副机之间的任务转发；已有的副机工具用于导出源码、在另一台电脑重新配置路径、账号和音频，并检查 OBS 音频隔离。换机运行时，所有微信操作仍发生在运行机器人的那台电脑上。这些迁移工具继续保留。

“UIA 快速模式”适配微信 4.1.15.56，保留已保存的 UIA 选择；没有旧选择时默认关闭。停服时可先保存选择。服务启动或运行中切换到 UIA 时，会核对本机组件和微信控件。完整控件查找在借用前台前完成，输入阶段只复核必要控件。文字、图片和原生语音沿用发送队列及回执确认，操作结束后归还原窗口。缺少必要控件或窗口发生变化时暂停，不拿过期坐标继续发送，也不自动切回其他发送方式。

升级前保存的“后台内存注入模式”不会自动开启 UIA；旧原生文字候选仍不可启用。当前 UIA 优先使用标准控件查询；微信未提供控件树时，现有组件可能修改当前进程内的一字节无障碍标志以启用控件访问。这不是加载发送 DLL 或调用内部发送函数，但也不是完全不修改进程内存；本次模式整合保留该现有 gate，没有删除或扩展它。2026-10-31 已在本机文件传输助手完成 UIA 文字、图片、原生语音的实际发送、数据库回执和焦点归还验收。这些受控单例不代表任意联系人或群聊、长期运行、锁屏、最小化发送已经通过；语音回执也不证明内容或音色一致。详见 [UIA 控件模式](BACKGROUND_CONTROLS.md) 和 [发送链路对比](SENDER_MODES_2026_10_31.md)。

## 开启和更换语音

打开“能力 → 语音服务”，可分别为识别和合成选择本地或云端。识别方式右侧可选 faster-whisper 方案，展开“编辑识别方案”可设置模型目录、识别语言和提示词。合成方式右侧可选“机器人语音”，展开后可编辑权重与参考音频。改好后点击底部“保存语音服务”，再分别点击所需方案旁的“使用此方案”。本地识别模型加载一次后会常驻，后续语音和视频音轨复用同一模型。切换为云端识别并保存，或从托盘退出桌面应用后，程序会自动释放识别模型。

根目录 [Start-WeChatAgent-Voice.cmd](../Start-WeChatAgent-Voice.cmd) 仍可用于单独维护语音服务，日常自动回复不要求先打开它。手动启动时保持窗口打开，用 `Ctrl+C` 停止。

语音仍需使用已配置的 VB-CABLE 线路；如果你把 Windows 默认录音设备切回了物理麦克风，发语音前需手动切回对应的 CABLE Output。程序不会自动更改默认设备。

换 GPT-SoVITS 模型时，展开“编辑权重与参考音频”，点“新建方案”，成套填写：

- 方案名称、GPT 权重 `.ckpt`、SoVITS 权重 `.pth`。
- 参考音频及其对应文字、参考音频语言。
- 回复语言、语速。

模型文件需先放入本机配置的模型目录。“扫描本机模型文件”只列出可选文件，不下载模型，也不自动切换。新方案填写后点“保存语音服务”，再点“使用此方案”加载新配置。页面显示加载进度和结果，已经生成的整条语音不会中途混用权重。

控制台目前没有“试听”按钮。更换方案用于下一次合成，已经进入发送队列的回复不会被临时改成另一种形式。

## 图片、GIF 表情和链接

在“表情包 → 本地图片与 GIF”导入本机 PNG、JPEG 或 GIF。每份不超过 20 MiB、4096 像素边长和 400 万画布像素，GIF 另限 200 帧，画布像素数乘以帧数不超过 8000 万。请保留原文件。名称与标签会用于机器人选择素材，本机路径仅供发送器读取。机器人可以根据对话选用这些素材。

同页的“账号共享表情池”管理手动添加和聊天收集的表情，依赖当前微信账号的读取服务。该服务暂时离线时，本地图片和 GIF 仍可独立管理。

静态表情配图以图片消息发送；GIF 保留原文件并通过微信发送为动态表情，不转换成第一帧。APNG 尚不支持。网页链接通过文字消息中的网址发送，尚不生成微信分享卡片。

图片和 GIF 与文字、语音共用发送队列和回复对象范围。静态图片回执确认微信数据库中新出现的图片消息；GIF 还会比对该动态表情记录与原文件的 MD5。两者都不声称对接收端逐像素或逐帧核验。

图片或 GIF 粘贴后被打断，只在当前运行实例仍能确认原草稿时继续。无法确认时会暂停，按“发送队列”的恢复提示停止服务、手动清理微信中的草稿，再解除这次草稿占用；不会通过重新粘贴猜测恢复，也不会重发结果不确定的消息。

## 提示需要恢复时

快速发送会直接粘贴要搜索的聊天名称和回复正文。如果剪贴板原本为空，粘贴后会恢复为空。能完整备份的内容也会照原样还原。开启本机发送配置中的 `allowClipboardReplacement` 后，遇到无法完整备份的格式，程序可用本次粘贴的搜索词、文字、图片、GIF 或文件替换原内容。发送过程中如果你又复制了新内容，程序会保留你新复制的内容。UIA 粘贴附件后还会确认微信已读取该附件，再继续发送。

队列提示“正在等待剪贴板”时，表示当前操作仍需能完整备份的剪贴板。可复制一小段普通文字，运行中的发送队列会自动重试。

如果队列显示“发送队列已暂停”，例如旧版本留下的剪贴板核验中断，先停止机器人并检查微信窗口和待发任务，再到“设置 → 诊断 → 发送与设备检查”点击“检查本机配置”和“恢复发送核验”，最后启动服务。

机器人上线后会按聊天补读离线消息。同一聊天的一段离线消息读完后，机器人结合前文，对最近一条符合该聊天规则的发言判断一次是否回复。聊天人格可以选择沉默。可在“设置 → 诊断 → 读取记录修复”查看进度。旧版恢复操作中断时，按该页提示还原记录后启动服务即可继续补读。
