# 自动回复与语音加载验收（2026-10-31）

分支：`feat/humanize`。代码与配置在本机运行，不依赖 Codex；保留 DSH、微信和本机读取组件。

## 已完成

- 机器人服务启动时并行启动 GPT-SoVITS，加载所选 GPT、SoVITS 权重与参考音频。读取和文字回复不等待模型加载，也不为预热占用微信焦点。
- 控制台“使用此方案”立即加载；保存当前正在使用的方案也立即重新加载。加载中、失败、已加载分别显示。相同服务实例与方案复用已确认的加载结果，不在每次合成时重复切权重。
- 回复形式由机器人选择：文字、原生语音、素材库中的静态图片或 GIF 表情，以及文字中的网址。移除固定文字/语音选项和多余的“回复方式”栏。
- “共享电脑模式”名称与互斥状态已接通。后台注入保持默认关闭。
- 图片使用明确导入的本机 PNG/JPEG/GIF 素材。素材库提供文件夹导入、名称、标签、启用和移除；不上传本地路径作为回复。GIF 通过原文件粘贴发送，保留动画，不转换为静态位图。
- 图片、GIF 与文字、语音共用队列调度和对象授权。粘贴后暂停只在原运行实例仍能证明同一草稿时恢复，不重复搜索或粘贴；丢失恢复依据时暂停，提供停止服务并手动清理草稿后的解除入口。发送结果不确定不会重发，GIF 也不承诺任意中断后自动续接。
- 控制台提供当前账号任务查看与允许范围内的暂停、继续、取消。退出控制台会等待由它启动的语音服务清理；机器人停止只关闭自己拥有的模型进程。
- 有用的上游更新已选择性移植，详见 [上游移植记录](UPSTREAM_0_4_1_PLUS.md)。

## 明确未完成和边界

**微信 4.1.15.56 内存注入仍被阻塞。** 已完成文字后端的隔离候选、协议与离线验证，但未找到能保证账号/服务对象在退出或切换账号时保持有效的同步入口。Loader 在操作目标进程前拒绝，NativeStart 和发送入口也拒绝；构建清单的可用性字段为 false。本轮没有把候选注入微信。此实验候选后续随旧发送链路退役。62 项离线检查不表示真实微信发送通过。

最初的静态图片验收只覆盖 PNG/JPEG；同日后续已完成非注入 GIF 文件粘贴路线的真实发送、动画帧观察和精确 MD5 回执，已将 GIF 纳入机器人可选素材。GIF 受 20 MiB、4096 像素边长、400 万画布像素、200 帧和 8000 万累计画布像素限制，损坏或超限文件不进入发送。APNG 尚不支持。链接为可点击网址，不生成分享卡片。

共享电脑模式和关闭后的逐字输入模式都能运行在主电脑或副电脑；已有副机脚本负责源码迁移、本机路径配置及音频检查，没有双机通信或主机分发任务的实现。当前没有副机硬件，未作副机现场运行测试。

日常入口与操作见 [日常使用](DAILY_USE.md)。
