# 选择微信程序

在“设置 → 微信与 DSH”选择已安装的 Windows x64 微信 `Weixin.exe`。桌面发送支持微信 4.2.0.53。控制台核对启动程序、核心文件的版本和腾讯数字签名，保存程序路径与版本。

已有登录窗口时，发送器会复用它。请确认登录的微信账号与读取服务中选择的账号一致。遇到版本不匹配，请查看所选安装目录中的完整版本号，并核对所用 WeChatAgent 发行版的说明。切换账号的步骤见[微信账号切换](ACCOUNT_SWITCH.md)。

切换显示器、窗口尺寸或 DPI 后，发送器会按实际窗口重新定位。OCR 和 UIA 的选择、离屏设置与手工标定见[桌面发送](FOREGROUND_INPUT.md)。
