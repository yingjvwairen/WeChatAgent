# OCR/UIA 桌面发送

WeChatAgent 通过已登录的 Windows 微信 4.2.0.53 发送文字、图片、GIF、文件、引用和语音。发送器根据所选模式，使用 OCR 识别界面或通过 Windows UI Automation（UIA）定位控件。可以在对应聊天的发送队列查看进度、回执和需要人工处理的操作。

## 界面设置

打开“设置 → 微信与 DSH → 微信发送方式”。先把发送按键设为与微信相同的 Enter 或 Ctrl+Enter，再按需调整以下选项。

| 设置 | 作用 |
| --- | --- |
| UIA 快速模式 | 开启后通过控件定位，关闭时使用 OCR。两种模式在操作窗口时都可能短暂借用焦点。 |
| 文字逐字输入 | 仅用于 OCR 模式下的文字正文，支持换行和 emoji。搜索词和含制表符的正文使用粘贴。 |
| 微信离屏 | UIA 模式下将微信放在显示区域之外。关闭此项、切回 OCR 或正常停止服务后，窗口恢复原位。 |
| 你在用电脑时延后发送 | 指定发送前等待键鼠空闲的时长。设为 0 时立即检查是否可以操作窗口。 |
| 暂停模拟输入自动发送 | 新回复可以排队，恢复后继续发送。已提交的任务仍可查询回执。单个任务可以在聊天的发送队列中暂停、继续或取消。 |
| 原生语音发送 | 通过已配置的 VB-CABLE 音频线路录制微信语音。另需在语音插件中为目标聊天授权。 |

UIA 优先使用微信已经提供的无障碍控件。缺少所需控件时，兼容组件可能修改匹配微信进程内的无障碍设置，然后重新检查控件。该设置持续至微信退出。希望只使用屏幕识别时，请保持“UIA 快速模式”关闭。

## 启动与定位

登录微信，选好 `Weixin.exe` 并验证读取账号。在连接设置中运行“检查模拟输入依赖”和“检查当前发送方式”，再启动服务。源码环境可用 `npm run desktop:setup` 准备组件。

OCR 在首次发送时按实际窗口生成布局，切换显示器、窗口尺寸或 DPI 后会重新定位。如果特殊布局始终无法识别，可以在本机标定。

### 在本机标定特殊布局

使用 OCR 自动定位遇到特殊显示布局时，可以为当前微信账号、程序、窗口尺寸和 DPI 保存一份人工标定。先停止机器人，再手动打开空草稿聊天，将微信放在实际使用的位置。坐标以微信客户区左上角为原点，单位为物理像素。每个矩形包含 `left`、`top`、`right`、`bottom`。

| 参数 | JSON 计划 | 采集时的窗口 |
| --- | --- | --- |
| `--plan` | 在 `layout` 对象中填写 `header`、`search`、`selfOpen`、`profileOpen`、`editor`、`send` 和 `pointerParkRect`。资料入口位于标题区域内，鼠标停放区选空白标题栏。 | 前台空草稿聊天 |
| `--focus-plan` | `rect` 为非活动窗口仍然可见的空白标题栏区域。 | 其他应用位于前台 |
| `--voice-plan` | 填写 `recordStartRect`、`mouseParkRect`、`cancelRect` 和 `submitRect`。 | 手动在文件传输助手显示录音界面，采集后及时手动取消 |

在项目目录运行 `node scripts/desktop-sender/calibrate.mjs --plan "D:\Calibration\layout.json"` 预检。加 `--save` 保存，覆盖已有同类标定需加 `--replace`。已绑定录音模板的编辑区发生变化时，先用 `--replace --discard-voice` 保存新布局，然后重新采集录音模板。其余两种计划采用相同用法。可以在同尺寸的自动布局基础上仅补录焦点或语音。程序只读取窗口，采集的像素摘要和账号绑定由本机生成。下次 OCR 发送优先采用匹配的标定，执行器仍在实际输入前核验窗口、目标和活动状态。停服后移除保存命令输出的单个方案文件即可恢复该尺寸的自动定位。

## 聊天名单

完成账号验证后，可以在机器人运行或停止时搜索和添加回复对象。好友和群聊都按当前账号中的完整微信标识授权。选择器会在显示名称下列出标识，同名聊天可以分别选择。

## 发送与恢复

联系人依据唯一微信号定位，也可使用数据库中唯一的备注、昵称或群名。定位存在歧义时，先在微信中设置可区分的名称，再继续处理队列。

发送器第一次接管目标聊天的输入框时会核验草稿。检测到人工草稿或无法确认编辑框为空时，任务暂停，供你处理后继续。自动布局结合编辑区画面和本地草稿探测核验空白。停服后，可在发送队列暂停、继续或取消尚未接管编辑框的任务。搜索被打断后，发送器会重新定位。正文已经输入时会保留进度，能够确认草稿归属后才继续。长语音分段录制，每段分别核对声学匹配和服务器回执。录音期间可以使用其他窗口，起录、提交或取消时可能短暂借用焦点。

如果队列提示草稿、录音或发送结果需要核对，先停止发送服务，到对应聊天检查实际消息和输入框，再到恢复区解除占用。已提交的任务保留原投递编号查询回执。

## 桌面与剪贴板

微信需要保持登录，Windows 会话已解锁，窗口处于可操作状态。锁屏、远程会话断开或键鼠活动打断操作时，任务会等待或暂停。前台占用时长可以在控制台的“前台占用与操作恢复”中查看。

粘贴后发送器会恢复已备份的剪贴板格式。如果此时你复制了新内容，保留你的新内容。默认设置遇到无法完整备份的格式时会暂停，可以复制一段普通文字后再继续。界面自动化仍受微信的平台规则和客户端变化影响。

## 窗口消息诊断

准备桌面组件并完成当前账号的窗口定位后，运行 `npm run desktop:window-probe -- --hwnd <十进制窗口句柄> --scope search-focus` 可只读检查搜索框，`self-profile-open` 检查资料入口。可选的 `--mode capture` 保存本地截图。`--help` 列出单次校准操作。诊断结果位于 `state/diagnostics`。

完成桌面组件构建后，运行 `npm run desktop:draft-inspect -- --executable "C:\Tools\Weixin\Weixin.exe" --hwnd <窗口句柄>`，可独立检查草稿窗口绑定。将程序路径和十进制句柄替换为本机值。
