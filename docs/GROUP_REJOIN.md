# 群聊改名与退群重进

WeChatAgent 使用当前微信账号下完整的群标识（例如 `room123@chatroom`）识别群。改名或者退出后重新加入同一个群，只要微信返回相同标识，原来的回复范围、人格和 DSH 会话就会继续生效。新建的同名群有自己的标识，需要单独添加和授权。

Reader 从联系人和会话列表读取群名与标识。重新进群后，如果控制台仍显示旧名称，先在微信里打开群聊，等待资料同步，再到“聊天”中搜索。选择器会显示完整标识，方便核对同名群。

桌面发送还需在微信窗口里确认目标。同名群可以分别接收消息；如果微信界面没有可唯一区分的搜索结果，发送会暂停。可在微信中设置能区分的群备注，再重试。
