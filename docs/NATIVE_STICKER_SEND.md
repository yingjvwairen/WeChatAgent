# 原生表情包发送

模型可以从已授权聊天可用的素材中选择表情。来源包括当前账号的共享表情池和项目本地的图片与 GIF。动态 GIF 保留动画。手动添加 PNG 或 JPEG 时，可选择保留原图，作为普通图片发送。[管理素材与表情](STICKER_MANAGER.md)

在“表情包 → 发送设置”调整账号默认值。若要单独设置某个聊天，打开“聊天 → 设置此聊天 → 能力与权限”。保存后对后续回复生效。已缓存的描述和标签可供模型选择素材。

发送队列按当前账号和目标聊天核对回执。收到匹配的新消息记录和非零服务器消息 ID 后，队列才显示已确认。响应丢失时，发送器通过原投递 ID 查询结果。[回复防重复与回执核验](TEXT_DELIVERY.md)

候选数量可在“表情包 → 发送设置 → 每轮候选数量”调整，范围 1–20，默认 8；只接受本轮实际提供的 S 编号。保存后用于新轮次，已提交请求保留原候选表供重试，降低数量不会破坏缓存恢复。较长消息会减少候选，为聊天正文预留空间。已缓存标签可以直接供模型选择；普通文字聊天不为凑满候选强制读图，未知素材仍最多补两张预览，图片输入上限仍为四张。素材不足时可以少于设置的上限，一轮仍只选一张表情。
